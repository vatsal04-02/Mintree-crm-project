# Decisions

One line per library added, with why (brief §3).

- react, react-dom 19 — brief §3 framework.
- vite 8 + @vitejs/plugin-react 6 + @rolldown/plugin-babel + babel-plugin-react-compiler — React Compiler on, per brief; plugin-react 6 moved Babel to a separate plugin.
- @tanstack/react-router + @tanstack/router-plugin — file-based typed routes, search params in URL.
- @tanstack/react-query — server state.
- @tanstack/react-table + @tanstack/react-virtual — ERP tables with virtualised rows.
- react-hook-form + zod + @hookform/resolvers — forms; Zod schemas will be generated by Orval later.
- tailwindcss 4 + @tailwindcss/vite — UI styling with tokens as CSS variables.
- radix-ui — accessible primitives (dialog, popover, dropdown, tooltip) for the shadcn-style kit owned in repo.
- cmdk — command palette.
- recharts — charts, coloured from tokens only.
- lucide-react — the one icon set.
- sonner — quiet toasts.
- zustand — UI-only state (density, locale, theme, palette open).
- @lingui/core, @lingui/react, @lingui/cli, @lingui/vite-plugin, @lingui/babel-plugin-lingui-macro — compile-time catalogues, English + Hindi.
- @fontsource/ibm-plex-sans, @fontsource/ibm-plex-mono — self-hosted fonts (no third-party font CDN on a factory network).
- @biomejs/biome — lint and format.
- vitest, @testing-library/react, @testing-library/user-event, jsdom, vitest-axe — component and accessibility tests.
