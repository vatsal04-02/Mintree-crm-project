# Design

Mintree Factory OS uses the frame ERPNext v16 Desk users know: a narrow icon rail of modules and a
panel for the open module (collapsible Create and Reports sections, white pill for the current
page), white content, Inter, near-black primary buttons, deep-mint links and focus, status pills
with a dot and a label. Tokens: `src/styles/tokens.css`; frame: `src/styles/layout.css`.

The full system — rules for navigation, status tones, components and the do-not list — is in
[`docs/FACTORY_OS_UI_DESIGN_SYSTEM.md`](../../docs/FACTORY_OS_UI_DESIGN_SYSTEM.md). Product
context: [`PRODUCT.md`](./PRODUCT.md).
