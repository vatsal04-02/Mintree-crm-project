# Design

Mintree Factory OS uses the framed-sheet world defined in `src/styles/tokens.css`: mint-grey
frame, one white work sheet, IBM Plex Sans with Plex Mono for codes only, one deep-mint accent
(`#1f6f55`), status chips that pair colour with an icon and a label, compact (32 px) and
comfortable (44 px) densities.

The full system — principles, tokens in use, status tones, components and the do-not list — is in
[`docs/FACTORY_OS_UI_DESIGN_SYSTEM.md`](../../docs/FACTORY_OS_UI_DESIGN_SYSTEM.md). Product
context: [`PRODUCT.md`](./PRODUCT.md).
